# bfnmovement.github.io

BFN's public web pages, published free by GitHub Pages at **https://bfnmovement.github.io**.

| Page | Address | File |
|---|---|---|
| Home | https://bfnmovement.github.io/ | `index.md` |
| BFN app privacy policy | https://bfnmovement.github.io/privacy/ | `privacy/index.md` |
| Delete your account | https://bfnmovement.github.io/delete-account/ | `delete-account/index.md` |

The app stores link to the privacy policy and the delete-account page, so **these addresses must never change**.

## How it works

- Pages are written in Markdown. GitHub turns them into web pages with Jekyll, using `_layouts/default.html` and `assets/css/style.css`.
- Every change is made in a pull request. When bfnmovement merges it, GitHub publishes the site within a few minutes.
- The pages load nothing from other websites (no fonts, scripts, cookies or analytics), so the privacy policy's "this website" section stays true.

## Keeping the policy true

The app's code lives in the private repo `bfnmovement/bfn-app`. Its `docs/legal/data-inventory.md` lists every kind of personal data the app handles, and `docs/legal/store-privacy-forms.md` holds the answers given to Apple and Google. Any ticket that collects new personal data, keeps it for a different time or adds a service that handles it updates all three in the same piece of work, and changes the "Last updated" date.

This policy was drafted with an AI assistant against the UK ICO's guidance on the right to be informed. It isn't legal advice. Have it checked by someone qualified before the app launches publicly.
